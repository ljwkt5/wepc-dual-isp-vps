## 原生 IP、住宅 IP、双ISP，三个词说的不是一件事

原生 IP 看的是注册地和机房位置是否一致。洛杉矶机房分配的 IP，WHOIS 里的国家是美国，这才叫原生。反过来，美国机房拿一批台湾 IP 做广播，在台湾本地平台眼里仍然是外来地址。

住宅 IP 看的是 ASN 归属。IP 挂在 Comcast、AT&T、中华电信这类民用宽带运营商名下才算家宽，挂在 IDC 运营商名下就是机房 IP。

双ISP 是同一个 IP 在两个民用 ISP 名下都有注册记录。它不给你两个 IP，WePC 的套餐默认只配 1 个 IPv4，需要多 IP 得单独处理。这一点在下单前必须搞清楚，很多人在套餐页看到"双ISP"就默认拿到两个地址。

TikTok、亚马逊、Netflix、ChatGPT 的风控会查 IP 的 ASN 归属，机房 IP 容易被判定成非真人流量。双ISP 的实际作用是一个 ISP 的段被批量标记时，另一个还有余量，相当于多一层缓冲，不保证永不被封。
